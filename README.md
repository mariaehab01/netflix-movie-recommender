# Netflix Movie Recommendation System

A simple content-based movie recommender system using user ratings and metadata from Netflix. This project identifies movies similar to a selected one by calculating correlations between user rating patterns.

## Features

- Loads and merges movie and rating datasets
- Builds a user-item pivot table
- Computes correlations to find similar movies
- Displays top recommended titles
